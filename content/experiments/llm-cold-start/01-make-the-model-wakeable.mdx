## The problem

The 7B held about 12 GB of the card around the clock. Turning it off broke
every app that called it until someone turned it back on.

## The change

The API gateway in front of the model scales it from zero to one replica when a
request finds it cold. An idle reaper scales it back to zero after 60 minutes,
counted from Ready and reset by every request. I picked 60 minutes over the 30
first proposed. Fine-tuned adapters persist across restarts.

## The result

The first live drill crashed the gateway: it couldn't handle the scaling API's
response for a deployment at zero replicas, and the model was unavailable for
about 16 minutes. Tests built from captured real responses fixed it, and the
drill script now restores the model if a drill fails. The next drill woke
cleanly, 151 seconds from request to first answer.

## The decision

Wake-on-request stays. Everything after this is about making the wake short.
